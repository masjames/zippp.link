We send (billable)

  • Interactive reply (review + 3 buttons)
  • Text “Tersimpan” + Sheet URL
  • Rare error / quota CTA (minimize)

We never send (cost control)

  • Marketing templates (Rp586.33)
  • “Sedang dibaca” / progress spam
  • Reminders, digests, cold outreach
  • Auth / Meta Business Agent

4. Calculator

A = WA Accepts / month
O = outbound Service msgs ≈ 2A
F = 1000 free Service msgs (confirm in Business Manager)

META_IDR = max(0, O − F) × 356.65
         = max(0, 2A − 1000) × 356.65

A_free_max  = 500 Accepts   (1000/2)
A_soft_max  = 400 Accepts   (our 800 cap)  → aim META = 0

Examples:
  100 Accepts → O=200  → META = 0
  400 Accepts → O=800  → META = 0  (soft-cap)
  600 Accepts → O=1200 → META = 200 × 356.65 = Rp71,330
 1000 Accepts → O=2000 → META = 1000 × 356.65 = Rp356,650
