# Destination

**Zippp is a personal finance OS.** Capture spend, track assets and goals, share a **Zippp Space** with anyone you trust. Web and Android are the same product. Pay on the web.

# Why

One ICP. One product. Stop spreading across restaurant / sales / reimbursement mills.

# Locked

- [x] ICP = personal finance (individual + shared Space)
- [x] Name for sharing = **Zippp Space** (never “family”)
- [x] Surfaces = web + Android parity for the product
- [x] Money = monthly subscription, fair-use usage %, checkout **web-only**
- [x] Capture = camera + manual + proactive remind (notification listener)
- [x] Product includes assets + financial goals

# Non-goals

- Kitchen / purchasing / sales / reimbursement as primary personas
- Android in-app purchase or pricing pages
- Calling collaborators “family”
- Accessibility-service bank scraping

# Done when

Anyone opening the Factory **Direction** tab can answer “what is Zippp?” in one glance without reading old companion specs.
