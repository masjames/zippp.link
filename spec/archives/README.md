# Archives

Superseded material. Read only for history. Do not implement from here.

```text
legacy/          Pre-pivot handoffs, implementation summaries, old flows
whatsapp/        WhatsApp-era plans, handoffs, cost models
plan-history/    Finished Phase 1/2 task plans and the old ship plan
discussions/     Older reviews, handoffs, and session summaries
```

Active specs stay at `spec/` root. Active plans stay in `spec/plans/`.
Active reviews stay in `spec/discussions/`.

Archive rule: if a document is not the current owner of a contract and is not
needed for an active task, move it here instead of deleting it.
